# J09 Health Staff Patients Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the complete J09 staff patient workflow using only real FastAPI/PostgreSQL contracts.

**Architecture:** Extend FastAPI with a staff-safe patient aggregate registration/search/detail contract and keep relationship access read-only for Health Staff. Build a feature-oriented React Native `patients` module consuming those contracts through React Query and Expo Router.

**Tech Stack:** FastAPI, SQLAlchemy async, PostgreSQL/Neon, Alembic, pytest, React Native/Expo Router, TypeScript, Axios, TanStack Query, React Hook Form, Zod, Jest/RNTL.

**Spec:** `docs/superpowers/specs/2026-08-28-j09-patients-design.md`

## Global Constraints
- Backend contracts and permissions are source of truth.
- No `Usuario` is created by staff patient registration.
- No fake MRN, clinical status, medications, alerts, family permissions, or patient data.
- `clinica:manage` is reused; no new permission names.
- Every behavior change receives tests in the same task.
